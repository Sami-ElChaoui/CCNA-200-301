## Méthode
Pour chaque sujet, je suis les mêmes étapes : premier contact avec le cours, pratique, prise de notes avec cartes Anki, puis un lab dans Packet Tracer.

Chaque dossier contient un résumé de ce que j'ai compris et de ce que j'ai fait, en général avec une capture de la topologie. Les énoncés des labs ne sont pas republiés : ils appartiennent à leurs auteurs.
